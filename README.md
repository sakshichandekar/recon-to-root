# Recon-to-Root

Hands-on penetration testing walkthroughs and VAPT-style reports performed in controlled lab environments.

---

## Overview

This repository contains practical penetration testing walkthroughs performed on intentionally vulnerable lab machines.

The objective of these labs is to practice:
- reconnaissance
- service enumeration
- vulnerability identification
- exploitation
- privilege escalation
- security documentation

Each machine includes step-by-step findings, observations, screenshots, and VAPT-style reporting.
